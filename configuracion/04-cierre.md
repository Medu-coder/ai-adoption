# Paso 4 — Cierre

1. **Resume todo lo configurado** en pocas líneas: dónde quedaron sus reglas, el proyecto (si lo creó) y los servicios conectados.
2. **Skills (habilidades listas para instalar):** mira en [`../sectores/`](../sectores/):
   - la carpeta de su profesión (si no tienes claro cuál le corresponde, pregúntale);
   - la carpeta `_comun/`, con skills útiles para cualquiera.

   Para cada skill disponible, explícale en una frase qué hace y pregúntale si quiere instalarla; si dice que sí, sigue las instrucciones de instalación de esa skill. Si no hay ninguna (o las carpetas están vacías), díselo con naturalidad.
3. **Recuérdale** que puede pedirte cuando quiera cambiar sus reglas, crear otro proyecto o conectar otro servicio.

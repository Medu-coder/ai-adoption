# AI Adoption

Kit público para ayudar a otras personas a adoptar la IA (Claude) en su día a día y en su trabajo.

## Idea

No se exporta un entorno personal: se **empaqueta el conocimiento**. Las instrucciones y flujos (skills, plugins, plantillas de proyecto) se diseñan y prueban aquí, y cada persona los instala en **su propia cuenta**, conectando sus herramientas con **sus propias credenciales**.

## Estructura

- `docs/` — enfoque, metodología y guías de instalación para usuarios.
- `plugins/` — plugins y skills listos para instalar, uno por perfil o caso de uso.

## ⚠️ Repositorio público: nunca secretos

Este repo es público y lo seguirá siendo. **Nunca** se suben claves, tokens, contraseñas, ficheros `.env`, datos personales ni datos de clientes. Los ejemplos usan siempre datos ficticios. Ver [AGENTS.md](AGENTS.md).
